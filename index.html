📖 How to Use

A quick guide for students. You can open it any time from the ☰ Menu.

1️⃣ Log in

  1. First time? Tap Create Account, type your full name, choose your school, and make a password (at least 6 characters).
  2. Next time, tap Log In with the same name, school, and password.
  3. You will only see reports from your own school.

😢 I lost something

  1. Open the ☰ Menu and tap Report Item.
  2. Choose Lost Item.
  3. Write the item name, a short description, where you last had it, and the date.
  4. Add a clear photo, then tap Submit Report.
  5. Check Items and Smart Matches every day. If someone found it, a Found report will appear.

🙌 I found something

  1. Open Report Item and choose Found Item.
  2. Fill in the details, add a photo, and tap Submit Report.
  3. You will get a private verification code. Write it down or tap Copy Code.
  4. Bring the item to the Guard House.
  5. Give the code only to the real owner.
💡 Before you share the code, ask the person to describe the item so you know it is really theirs.

🔎 Is it my item? (claiming)

  1. Open Items. Search by name, or filter by Lost, Found, or Returned.
  2. Find your item in a Found report.
  3. Ask the finder for the code and pick up your item at the Guard House.
  4. Type the code under Owner Verification and tap Verify & Mark as Returned.

✅ Good to know

  1. The code is saved only on the phone or browser you used to report. Do not clear your browser data until the item is returned.
  2. Returned items are removed automatically after 24 hours.
  3. Stuck? Tap the 💬 button at the bottom right to ask the Recovery Helper.
  4. Using a shared device? Tap Logout in the ☰ Menu when you are done.
